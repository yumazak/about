## 概要

事業・コーポレート部門の業務プロセスを理解し、業務設計・データ基盤・業務システム・AI 機能を横断してリードするエンジニアリングマネージャー。

現在もリードエンジニアとして開発の第一線に立ちながら、採用・人事評価・メンター・チーム運営を担当している。

## 職務経歴

### 株式会社プレックス（HRテック） 2024.01 〜 現在

**開発本部 コーポレートチーム マネージャー**

社内システム・データ基盤・業務改善を横断。各プロジェクトは自ら立ち上げ、立ち上げ後はリードを担当。

#### BPR・kintone プラグイン開発基盤

- バニラ JavaScript 中心だった開発を TypeScript / Vite / React へ移行
- Turborepo によるモノレポ、雛形、デプロイ CLI を整備
- 複数アプリを横断する情報表示、距離計算・地図表示、AI メール生成などのプラグインを開発・運用
- **46本**の kintone プラグインを展開

#### 法人データを活用した分析・検索アプリ

- Next.js / React / TypeScript / Ruby on Rails / BigQuery で、法人データの検索・分析と業務状況の一元管理を実現
- BigQuery から Cloud SQL への同期、検索用 Cube.js モデル、運用通知を整備
- データを現場の業務フローへ接続

#### データ基盤・外部データ連携

- dbt / Airbyte / BigQuery / Cube.js で、データ連携〜変換〜可視化までの基盤を構築
- **dbtモデル810本**を運用
- 既製コネクタのない SaaS については、TypeScript SDK を用いた Airbyte コネクタを開発
- 勤怠・通話データなどの連携を実現
- BigQuery のデータセット・サービスアカウント・アクセス権を Terraform で管理

#### 社内汎用 API 基盤

- Ruby on Rails / PostgreSQL で、全社の業務システムが依存する共通 API を立ち上げ
- **モデル209本**、約20の外部サービス連携、定期処理、データ更新・通知を集約
- 顧客とのメッセージ・通話対応を複数担当者で扱う業務プロダクトも開発
- テンプレート、タグ、添付送信、既読管理、業務情報の定期同期を実装

#### LLM・検索技術を用いた業務支援

- Gemini API / Mastra / AI SDK / Ruby LLM を活用
- 音声要約、メール内容判定・生成などの社内初 AI 機能を企画・開発
- 埋め込みモデルによる類似問い合わせ検索
- Playwright と LLM を組み合わせたデータ収集・要約・フィードバックの業務自動化バッチを実装

#### インフラ・開発生産性

- Terraform / Helmfile / GitHub Actions で基盤のコード化と CI/CD を整備
- Four Keys の可視化ダッシュボードを構築し、デプロイ頻度・変更リードタイムを継続的に計測
